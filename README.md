# Timimt.github.io

宇奕_zoran 的個人技術 Blog：關於我、CS Daily Knowledge 入口、踩坑紀錄、專案與學習筆記。

- 框架：Astro + TypeScript + CSS design tokens
- 內容：`src/content/` 的 Markdown（GitHub 是內容唯一權威來源）
- 部署：GitHub Actions 自動建置到 GitHub Pages
- 網址：<https://timimt.github.io/>

## 本機開發

```bash
npm install
npm run dev
```

## 建置

```bash
npm run build
npm run preview
```
